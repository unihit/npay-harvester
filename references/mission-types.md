# 네이버페이 포인트 미션 유형별 수령 매뉴얼

네이버페이 포인트 리워드 링크는 형태에 따라 요구되는 사용자 인터랙션이 상이합니다.

---

### 1. 캠페인 클릭 적립 (`campaign2.naver.com/npay/v2/click-point`)
* **특징:** 벨킨, 브랜드데이, Npay 혜택/신용점수 등 대표적인 클릭 리워드 링크.
* **수령 조건:**
  1. 페이지 진입 후 화면 중앙의 `포인트 받기` 버튼 클릭.
  2. 리다이렉트된 브랜드 페이지/스토어에서 **최소 3초 이상 체류**해야 포인트가 적립됨.

### 2. 연금 혜택 확인 (`point.pay.naver.com ... pensionmission`)
* **특징:** 금융 연금 펀드 소개 페이지 (일주일 단위 리셋).
* **수령 조건:**
  - 하단의 운용사(미래에셋자산운용, 삼성자산운용) 배너의 `확인하기` 버튼을 각각 클릭. (각 10원, 총 20원)

### 3. 마이카 배너 미션 (`mycar.naver.com`)
* **특징:** 중고차금융, 렌트카, 방문평가 등 4~5개 제휴 배너.
* **수령 조건:**
  - 페이지 내 `클릭 ?원`, `방문 혜택` 배너를 각각 클릭하여 해당 서비스 페이지 진입 시 각 2원 적립.

### 4. 보험 방문 랜덤 포인트 (`insurance.pay.naver.com`)
* **특징:** 계정당 하루 3회 참여 가능한 보험 페이지 방문 리워드.
* **수령 조건:**
  - `https://insurance.pay.naver.com/point`로 이동하여 일일 3개 배너(`insu_v3_benefits_clk`)를 순차 방문.

### 5. 모바일 웹 전용 미션 (`home.pay.naver.com`, `new-m.pay.naver.com`)
* **특징:** PC 웹으로 접속 시 다른 페이지로 리다이렉트되어 적립 버튼이 나타나지 않음.
* **수령 조건:**
  - 반드시 CDP를 통해 모바일 `User-Agent`와 모바일 뷰포트(`width: 412, height: 915`)를 설정한 상태로 접속해야 함.
  - 결제홈 스크롤 미션의 경우 15초 이상 연속 상/하단 스크롤 유지 필요.
