# 네이버페이 포인트 미션 유형별 수령 매뉴얼

네이버페이 포인트 리워드 링크는 형태에 따라 요구되는 사용자 인터랙션이 상이합니다.

---

### 1. 캠페인 클릭 적립 (`campaign2.naver.com/npay/v2/click-point`)
* **특징:** 벨킨, 브랜드데이, Npay 혜택/신용점수 등 대표적인 클릭 리워드 링크.
* **수령 조건:**
  1. 페이지 진입 후 화면 중앙의 `포인트 받기` 버튼 클릭.
  2. 리다이렉트된 브랜드 페이지/스토어에서 **최소 3초 이상 체류**해야 포인트가 적립됨.

### 2. 연금 혜택 확인 (`point.pay.naver.com ... pensionmission`)
* **특징:** 금융 연금 펀드 소개 페이지 (일주일 단위 리셋).
* **수령 조건:**
  - 하단의 운용사(미래에셋자산운용, 삼성자산운용) 배너의 `확인하기` 버튼을 각각 클릭. (각 10원, 총 20원)

### 3. 마이카 배너 미션 (`mycar.naver.com`)
* **특징:** 중고차금융, 렌트카, 방문평가 등 4~5개 제휴 배너.
* **수령 조건:**
  - 페이지 내 `클릭 ?원`, `방문 혜택` 배너를 각각 클릭하여 해당 서비스 페이지 진입 시 각 2원 적립.

### 4. 보험 방문 랜덤 포인트 (`insurance.pay.naver.com`)
* **특징:** 계정당 하루 3회 참여 가능한 보험 페이지 방문 리워드.
* **수령 조건:**
  - `https://insurance.pay.naver.com/point`로 이동하여 일일 3개 배너(`insu_v3_benefits_clk`)를 순차 방문.

### 5. 모바일 웹 전용 미션 (`home.pay.naver.com`, `new-m.pay.naver.com`)
* **특징:** PC 웹으로 접속 시 다른 페이지로 리다이렉트되어 적립 버튼이 나타나지 않음.
* **수령 조건:**
  - 반드시 CDP를 통해 모바일 `User-Agent`와 모바일 뷰포트(`width: 412, height: 915`)를 설정한 상태로 접속해야 함.
  - 결제홈 스크롤 미션의 경우 15초 이상 연속 상/하단 스크롤 유지 필요.

### 6. 쇼핑라이브 방송 미리보기 (`external-token.pay.naver.com/entry/pincrux`)
* **특징:** 핀크럭스(Pincrux) 연동 쇼핑라이브 방송 예고 리스트 (1원씩 최대 20~25건 지급).
* **수령 조건:**
  - `shopping-live.html` 진입 후 **반드시 `라이브 더 보기`를 클릭**하여 가려진 Coming Soon(오전 및 오후/저녁 방송 전체) 카드를 전부 전개해야 함.
  - 각 항목(`.comming-list-item`, `ready-scroll-box`)의 onclick 핸들러에 바인딩된 `live-view.html?bno=...` 링크를 추출하여 직접 방문.
  - `1초 후 적립 / 1원 적립 완료` 토스트가 뜰 때까지 각 페이지당 **최소 3.5초 체류**.

---

### 7. 미적립 원인 분류 및 진단 기준 (Uncollected Reasons Taxonomy)

수령되지 않은 항목에 대해 사용자가 직관적으로 이해할 수 있도록 표준화된 원인 코드를 매핑하여 보고합니다:

| 분류 코드 | 원인 및 현상 | 대표 사례 |
| :--- | :--- | :--- |
| **선착순 조기 마감** | 오픈 시간(예: 매일 08시 등) 선착순 한도 마감으로 접속 시 네이버페이 메인 등으로 리다이렉트됨 | 제주항공 선착순 미션 등 |
| **중복 적립 불가 / 이전 수령** | 전일 또는 최근 동일 캠페인에서 이미 포인트를 수령하여 버튼이 없거나 중복 지급 제외됨 | 플리마켓, 우리은행, 르무통 등 |
| **리셋 주기 미도래** | 계정 참여 시점 기준 일주일(7일) 등 쿨다운 주기가 아직 경과하지 않음 | 연금 혜택 미션 (미래에셋/삼성) |
| **계정 타깃 미노출** | 계정 등급, 이용 실적, 이벤트 타깃팅 조건에 따라 페이지 내 적립 배너/버튼이 렌더링되지 않음 | 모바일 페이 홈 중앙 3원 버튼 등 |
| **당일 미션 미진행** | 이벤트 기간 종료 또는 당일 출제된 퀴즈가 없는 날인 경우 | 랜덤 포인트 퀴즈 미출제일 |
| **제휴사 정산 지연 / 마감** | 외부 제휴사(Pincrux, Adison 등) 토큰 할당량 소진 또는 실시간 정산 지연 | 쇼핑라이브 예고 1원 적립 등 |
