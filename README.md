# NPay Harvester (네이버페이 포인트 자동 수령 스킬)

Google Antigravity(AGY) 및 Ego Lite 브라우저를 기반으로 동작하는 **네이버페이 포인트 리워드 자동 수령 스킬**입니다.

뽐뿌, 클리앙, daissue 등에서 공유되는 매일의 네이버페이 모음 글 링크를 입력받아, 백그라운드 격리 브라우저(Task Space)에서 로그인 세션을 유지한 채 모든 포인트를 자동으로 적립합니다.

---

## 🚀 주요 기능
* **지능형 링크 분석**: 텍스트 내 포함된 URL 자동 추출 및 뽐뿌 단축/리다이렉트(`s.ppomppu.co.kr`) 자동 디코딩
* **유형별 자동 인터랙션**:
  * **캠페인 클릭 적립**: `포인트 받기` 버튼 클릭 후 3.5~4.5초 체류 보장
  * **연금 혜택**: 미래에셋/삼성자산운용 펀드 확인 미션 수행 (+20원)
  * **마이카 배너**: 중고차/렌트카 등 4~5개 제휴 배너 순차 방문 (+최대 12원)
  * **보험 방문**: 일일 3회 보험사 방문 랜덤 포인트 적립
  * **모바일 웹 에뮬레이션**: PC 브라우저 환경에서도 모바일 전용 미션(UA/Viewport 변경) 자동 처리
* **정산 리포트**: 적립 전/후 잔액 비교 및 당일 적립 상세 내역 표 출력
* **디스코드 카드형(Embed) 알림**: 웹페이지 전체 텍스트 덤프 없이 당일 적립액, 잔액 변동, 미적립/오후 2시 대기 항목을 가독성 높은 Embed 카드로 디스코드 웹훅 자동 전송
* **안전한 격리 실행**: Ego Lite의 Task Space를 활용하여 사용자의 활성 탭에 간섭 없이 백그라운드 처리 및 리소스 자동 회수

## 📦 다른 PC에서 설치 및 사용 방법

### 1. 선행 요구 사항
* [Ego Browser](https://github.com/unihit/antigravity-ego-lite) 설치
* Ego Browser에서 네이버 로그인 1회 완료 (세션 상속)

### 2. 스킬 설치
다른 PC의 터미널에서 다음 명령어를 실행하여 전역 스킬 디렉터리에 복제합니다:

```bash
git clone https://github.com/unihit/npay-harvester.git ~/.gemini/config/skills/npay-harvester
```

### 3. 사용 예시
Antigravity 채팅창에 다음과 같이 입력하세요:

```text
오늘자 네페 모음 글 적립해줘:
[뽐뿌나 커뮤니티에서 복사한 링크 모음 본문 붙여넣기]
```
